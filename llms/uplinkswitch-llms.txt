# UplinkSwitch

> One API key and one base URL for Claude, GPT, Gemini, Grok, DeepSeek, Qwen, Kimi, GLM and MiniMax chat models, priced below the developers' list prices, plus image, video, speech and 3D models (Nano Banana, GPT Image, Seedream, FLUX, Veo, Seedance, Kling, Wan, ElevenLabs, Tripo). Prepaid credit, no subscription.

- Base URL: https://api.uplinkswitch.com/v1 (OpenAI, Anthropic and Gemini SDK formats)
- Auth: `Authorization: Bearer sk-uplink-live-...` (or `x-api-key` / `x-goog-api-key`, as each SDK sends it)
- Keys: https://uplinkswitch.ai/console
- OpenAPI 3.1 document: https://api.uplinkswitch.com/openapi.json (every customer route, request and response shape, and the x-uplink-* headers)

## Prices (JSON, no key needed)

- [Chat models](https://api.uplinkswitch.com/v1/catalog): customer price and developer list price per million tokens
- [Media models](https://api.uplinkswitch.com/v1/catalog/media): settings and price per image, second or generation
- [Price index](https://uplinkswitch.ai/pricing-index): every listed chat model with a developer list price, our price next to it, as [JSON](https://uplinkswitch.ai/pricing-index.json) and [CSV](https://uplinkswitch.ai/pricing-index.csv)
- [AI catalog](https://uplinkswitch.ai/ai-catalog.json): every chat and media model in one document, with our price, the developer's list price, the endpoints and formats it answers, and its page
- [API discovery](https://uplinkswitch.ai/.well-known/api-catalog): RFC 9727 Linkset pointing at the OpenAPI document, the catalogs, the price index, proof and status
- [MCP server](https://api.uplinkswitch.com/mcp): Streamable HTTP, stateless. Tools list_models, list_media_models, estimate and proof need no key; chat is billed to the `Authorization: Bearer sk-uplink-live-...` header. Server card at https://api.uplinkswitch.com/mcp/server-card, AI catalog at https://uplinkswitch.ai/.well-known/ai-catalog.json. Setup for Claude Code, Cursor and Cline in their guides.
